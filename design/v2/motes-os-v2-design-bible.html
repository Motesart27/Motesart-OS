1 · Product and aesthetic principles

The interface is not a conventional dashboard. It is a cockpit: one operator, one attention field, one coherent hierarchy. (Grounding: handoff §5 success definition; orders “Tone of the work.”)

Quiet authority

Graphite surfaces, restrained accents, deliberate spacing, minimal decorative noise. Silence is part of the design.

Executive compression

At most six signals deserve his eyes; everything else is handled. Density is earned by hierarchy, not by cramming.

Fidelity over invention

Tokens, timing, geometry, and behavior are locked. Builders do not improvise design; reviewers do not redesign.

Motion with purpose

Motion explains state and continuity. It never performs for its own sake.

Accessible by default

Keyboard, reduced motion, contrast, focus visibility, semantic signaling, and 44px touch targets are release gates.

One system, two trees

Desktop and phone share tokens and data hooks but intentionally use separate layout component trees.

Guidance (non-normative): if removing an animation or a glow does not reduce comprehension, it probably does not belong. The bar is “the glow restraint, the silence” (orders, Tone of the work).

Tier usage rules

Accent marks
--info…--exec are chart-grade marks, CVD-validated as a set on #161A21: chart ink, edge bars, beacons, fills. Never body text. The set is closed — no additions or substitutions.
Accent text
--*-t tier (≥5.7:1 on all surfaces) is the only lawful accent-colored text, and also the tier used for glowing signal dots (mockup-evidenced).
Dim fills
--*-d tier for chips, pills, tinted icon squares, ribbons, and tinted buttons. Never hand-mixed alphas for these roles.
Text tiers
text-1 for values and primary content; text-2 for body/secondary; text-3 for labels/metadata — and text-3 is the contrast floor: nothing dimmer ships, anywhere.

The value law (governs every review)

V1 — Tokens are exhaustive
For the five protected classes — color, duration, easing, radius, shadow — tokens.css plus the named standards in §5/§6 are the complete lawful set for authored values.
V2 — Mockup recipes are lawful constants
Where law commands porting mockup CSS exactly, the mockups’ internal component constants (state-orb gradients, track tints like rgba(255,255,255,.07), glow shadows, the wallet-card surface gradient) are lawful as component recipes, documented in §4–§6. They never enter tokens.css and never generalize to new uses.
V3 — Deviations don’t amend law
Where a mockup value contradicts a handoff/token value (§12.2 registry: 18px grid gap, .78 glass-hi, 24px phone card radius), the handoff/token value is law; the deviation is recorded and surfaced to Denarius at the affected phase gate. Nobody — builder or reviewer — resolves these silently.
V4 — Missing value ⇒ BLOCKED
A needed value with no token, named standard, or mockup evidence is a BLOCKED note to the architect seat, never an improvisation.

Zone labels
11px, weight 600, uppercase, letter-spacing .14em, text-3 — followed by a 1px hairline rule (stroke-1) and an optional “Open ‹module› →” link (11.5px, text-3, hover info-t).
Ambience
The stage background is --bg-0 with a fixed, non-scrolling depth field of exactly two radial gradients (info at .05 alpha top-center; ai at .035–.05 alpha far corner) — “a faint depth field, never a gradient wash” (mockup comment). 4 · Component language

Every component exposes default, hover, focus, active, disabled, loading, empty, and error states where applicable. All interactive elements: visible hover state, focus ring (2px --info, 2px offset), ≥AA contrast. Anatomy below is mockup-exact; port the reference CSS, don’t reinterpret it.

Desktop components

Button
Variants: primary (info fill) · ghost (transparent + stroke-2 border) · ai (ai fill) · danger (crit fill). 14px/600, radius --r-s, padding 11×15, --e1. Hover: −2px lift + --e2. Press: scale(.97). Focus ring standard. Disabled (ruling DB-G8): native disabled attribute on real buttons. One recipe, all four variants — variant hue never survives into disabled. Filled variants: --bg-3 fill, --text-3 label, inset 0 0 0 1px var(--stroke-1) in place of elevation, border 0. Ghost: transparent fill, --stroke-1 border, --text-3 label, no shadow. Geometry, type, and radius unchanged; transform: none; platform-default cursor; hover/press rules guarded :not(:disabled); never lifts, presses, glows, or dispatches; not focusable (native), so the focus-ring spec is unaffected. Button-only: any other component’s disabled presentation requires its own ruling.
Card
Opaque surface: --bg-2, stroke-1 border, radius --r-m, --e1. Liftable cards (.lift): hover −3px translate + .35° rotate + --e3 + stroke-2 border. Tilt cap ≤0.4° (law). Cards are not glass.
Panel
Glass surface: --glass + blur(20px) saturate(140%), stroke-1, radius --r-l, --e1. Hover: border to stroke-2 + --e2 — panels brighten, they do not lift. Panels host zone-level content (hero, business health).
Chip
11.5px/600, 4×10 padding, pill radius. Color pairing law: -d fill + -t text of the same accent. Six accents only; color never the sole carrier (count/label text always present).
StatCard
Label (11px, text-3, .04em) · value (19px/700, tabular numerals) · delta (11px/700; up = good-t, down = crit-t) · optional 26px sparkline slot or live-status line. Tile: rgba(255,255,255,.028) fill, stroke-1, radius --r-s; hover −2px + brighten.
Signal feed row
7px severity dot (accent-text color + 9px glow at ~.5 alpha) · 13.5px text with bold text-1 emphasis · reveal arrow (fades in, slides 4px) on hover · row hover: rgba(255,255,255,.045) + 2px translateX. Max six rows — the six-signal law is structural.
Agenda slot
Mono 11px time (52px column) · 3px×22px color bar (severity/module accent) · 13px title + 11px text-3 subline · hover wash.
Project card (pcard)
3px left edge bar (module accent) · 14.5px/600 title · 12px meta with text-2 bold emphasis · progress bar · foot row with mono percentage.
ProgressBar
4px track rgba(255,255,255,.07–.08), pill radius; fill = single accent color + glow 0 0 10–12px rgba(accent,.5); fills by the 1.4s named standard (§5). The 10px gradient demo bar in the old reconstruction is NOT a product spec — product bars are 4px, solid accent, per the references.
ProgressRing
Hand-rolled SVG: 52px (desktop) / 56px (phone), r=22/24, stroke 5, rounded caps, hairline track rgba(255,255,255,.08), −90° start. Fill animates stroke-dashoffset 1.4s --ease (paint-only). Center value 13–15px/700–800 with 7.5–8.5px uppercase sublabel.
Toast
Container aria-live="polite", fixed bottom-right 22px. Toast: glass-hi + blur(20px), stroke-2, radius 14px, --e3, min-width 280px, 8px severity dot with glow. In: 300ms --spring (24px slide + fade). Out: 220ms --ease. Dwell ~3s. Quiet: no sound, no stacking chaos, never used for routine refresh.
Kbd
Mono 10.5–12px on rgba(255,255,255,.06), hairline border with heavier bottom edge, 5–7px radius.
Quick action (qbtn)
Column icon+label tile, --bg-2, stroke-1, radius --r-m. Hover: −3px + scale(1.02) on --spring, icon tints ai-t. Press scale(.97). Result: optimistic toast “‹action› → routed to ‹executive›”.
MyaBar
Fixed bottom 22px, centered over the stage: translateX(calc(−50% + 32px)) compensates the 64px rail. 48px pill: glass-hi + blur(24px) saturate(150%), stroke-2, --e3 plus ambient purple glow 0 0 34px rgba(150,120,242,.12). Hover: −2px, glow to .22, border rgba(150,120,242,.4). Contents: 22px breathing orb · “How can I help?” (13px text-2) · Space hint. Phase D adds the persistent voice toggle here (law, §10).
Command palette
Veil: rgba(5,6,8,.55) + blur(6px), fades --t-med. Sheet: fixed at top 16%, width min(640px, 92vw), glass-hi + blur(28px) saturate(160%), stroke-2, radius --r-xl, --e3 + 0 0 60px rgba(150,120,242,.14). Entrance: scale(.97→1) + fade, --t-med --ease; interactive ≤120ms from keypress (ruling C3). Pin row: 26px state orb · 17px/500 input (placeholder “How can I help?”) · 34px mic button (hover: ai-t + ai-d + purple border). Body ≤380px scroll: “Suggested” chips (Morning Brief · Continue MLI · Review SOM · Student today · Business health · Book sales · Upcoming travel), then “Everything” results — rows of 28px icon square (-d fill, -t glyph), 13.5px title + 11px subline, mono action hint, selected/hover wash rgba(255,255,255,.06). Empty result state hands off to Mya: “Nothing yet — Mya will take it as a request. Press ↵ to hand it off.” Footer strip: ↵ run · esc close · status line. Focus is trapped while open and returns to the exact prior element on close (law; the static mockup does not implement this — gap G3).

R-1 · 60fps rule
Animate transform and opacity only (law) — with the named R-2 exceptions.
R-2 · Geometry exceptions
Exactly three mockup-evidenced width animations are lawful because they are paint-contained and provably reflow nothing outside themselves: rail width (fixed overlay) · progress-bar fill (overflow-hidden track) · deck dot stretch. SVG stroke-dash animations are paint-only and unrestricted. Nothing else may animate geometry; a fourth exception requires an architect ruling.
Reduced motion
Collapses everything to opacity or instant state: boot absent, zone entrance instant, draw-ins render final state, parallax off, breathing stopped, transitions ≤.01ms. Verified every phase (DoD).

6 · Graph and data-visualization standards

SVG only
Charts, sparklines, and rings are hand-rolled SVG exactly as in the references. No chart libraries, ever (AGENTS.md).
Sparkline
2px accent stroke, round caps/joins, vector-effect: non-scaling-stroke, 2.4px end dot; no axes when trend alone is the purpose; data window fits min/max with ~2–8% padding. Desktop stat slot 26px tall; phone business 64px with gradient area (accent at .2 → transparent).
Area chart (Z3)
150px tall; Catmull-Rom smoothed line, 2px --info stroke; gradient fill --info .22 → 0; exactly three horizontal gridlines rgba(255,255,255,.045); endpoint date labels only (mono 10px, #8A93A1); range segmented control 7D/30D/QTD.
Crosshair tooltip
1px stroke-3 vertical line + 9px info-t dot (2px bg-2 ring, soft glow) + glass-hi tooltip (blur 16px, stroke-2, --e3): 15px/700 tabular value over 10.5px muted label; tooltip x-clamped inside the plot; hidden on leave; --t-fast fades. A keyboard-accessible equivalent for the values is required (gap G6 — design lands with the Phase C PLAN).
Progress bars & rings
Per §4 anatomy; bounded progress only; the state is always labeled in text (percentage, count, days) — never fill alone.
Scale truthfulness
Trend visuals are deliberately windowed to the data range (evidenced: min×.92–.94, max×1.03–1.04) — they show shape, not absolute magnitude. Grounding is mandatory: endpoint labels, crosshair values, or an adjacent tabular value. Misleading emphasis = glow/area beyond the §4–§6 recipes, unlabeled cropped bars presented as absolutes, or visual exaggeration a label does not correct.
Draw-in policy
Once per mount; re-draw on user range change; never on passive data refresh; never on resize (ruling C7).
Data states
Every data tile designs loading (skeleton), quiet empty (“suggests, never begs”), partial/stale (marked, subtle), and error states — per-tile degradation, no cascades (handoff Phase C). The mockups render success states only; state visuals land with each phase’s PLAN (gap G6).
Color
Chart ink comes from the six accent marks; severity mapping is fixed (crit red · exec gold · ai purple · warn amber · info blue · good green). One accent per series as evidenced; no decorative multi-color fills.

7 · Accessibility gates

Contrast floor
#8A93A1 (4.8:1) is the dimmest text that ships; interactive elements ≥AA; accent text uses the -t tier (≥5.7:1).
Focus ring
2px --info, 2px offset, on every interactive element (:focus-visible), always visible against its surface.
Touch
≥44×44px effective targets on phone. Small glyphs (22px tick) are lawful only inside a full-row hit area that meets the minimum.
Keyboard map
Space / ⌘K open the palette (suppressed while typing in any input) · E toggles Executive Mode (suppressed while typing) · Esc closes/exits — including while typing, and always exits listening without dispatch · arrows navigate results and the phone deck · Enter runs/selects · Enter/Space toggle focusable phone rows. Every rail item and interactive element is Tab-reachable.
Focus containment
The palette traps focus while open and returns it to the exact prior element on close (law — the static mockups do not implement the trap; builders must, gap G3).
Reduced motion
Collapse to opacity/instant per §5; boot skipped; parallax off; breathing stopped.
Semantics
Meaning never rides on color alone — severity dots pair with text, chips carry counts, states carry labels. Real controls (button, input, role="dialog" aria-modal, role="tablist" for the focus switcher, aria-pressed on EXEC, aria-current on the active rail item) as evidenced in the references.
Live regions
Toast container aria-live="polite"; phone status pill role="status". Asynchronous updates announce politely — never assertively.
Names
Icon-only controls carry aria-labels (bell “Notifications”, mic “Talk to Mya”, search pill “Search everything”, MyaBar “Ask Mya”, deck “Cards — swipe”).

8 · Desktop behavior contract

Greeting & clock
Greeting by hour (morning <12, afternoon <18, else evening) + live dateline, 30s refresh. This visual greeting layer is distinct from Mya’s locked voice greeting pool (handoff Phase C).
Signal feed
Max six ranked signals (crit > exec > ai > warn > info > good), each: severity dot, one-line summary with bold emphasis, hover reveal arrow, action on click. Sub-line names the count (“6 signals deserve your attention”). Handled line closes the brief: green check + summary + “View log →”.
Today column
Right column of the hero panel (1.5fr/1fr split, hairline divider, faint wash): date header, count chips (meetings/invoices/tasks), agenda slots with sanitized titles (law).
Countdowns
Computed client-side from event dates (convention Jul 19, birthdays) — dates live in data, not in engine rules.
Palette
Opens ≤120ms (interactive; ruling C3); merged “Everything” index; arrows/Enter select; Esc closes and restores exact prior focus; typing suppression law; unmatched query is handed to Mya as a triage task (create_task_core path — handoff Phase D); suggestion chips per §4; mic surfaces the existing voice-state machine, never a new one.
Executive mode
E or the EXEC button. Non-CEO zones: opacity .10 + blur(5px) + saturate(.6) + scale(.985) + pointer-events none. CEO surfaces gain gold framing (hairline rgba(178,132,55,.4) + soft ring + ambient gold glow). The EXECUTIVE MODE band appears above the grid: ◆ tag in exec-d/gold hairline + gradient rule. EXEC button inverts to solid gold with dark text, aria-pressed true. One confirmation toast; no other noise.
Focus modes

Tagged project cards gain a purple hairline + soft glow. The focus ribbon appears in the hero: ai-d fill, purple hairline, breathing dot, mode status line. Mode suggestions are dismissible toasts only — never auto-switch (law).
Quick actions
